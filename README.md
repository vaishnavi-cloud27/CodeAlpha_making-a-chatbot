# CodeAlpha AI Chatbot 🤖

## Project Description
An AI-powered **retrieval-based chatbot** built as part of the **CodeAlpha Cloud Computing Internship**. The chatbot uses pattern matching to understand user queries and delivers instant, accurate responses — no server or backend required.

---

## Features ✨
- 💬 Real-time conversation with instant replies
- 🧠 Pattern-matching based response engine
- ☁️ Answers questions on Cloud Computing, AI, Python, Cybersecurity & more
- 😂 Tells jokes and shares fun facts
- 📱 Fully responsive — works on mobile & desktop
- 🌙 Modern dark-themed UI
- ⚡ No backend or database needed — runs fully on the browser

4. Start chatting! 💬

---

## How It Works 🧩
1. User types a message
2. The JavaScript engine converts it to lowercase
3. It scans the **Knowledge Base** for matching keywords/patterns
4. If a match is found → the linked response is displayed
5. If no match → a friendly fallback message is shown
6. A typing animation simulates a natural conversation feel
